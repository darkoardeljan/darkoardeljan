## 🧭 What I do

## ⭐ Featured projects

**[E-Connect&Fix Elektrotechnik](https://github.com/darkoardeljan/e-connect-fix-showcase)** — website for an
electrical contractor in Ulm. Live at [econnectfix.de](https://econnectfix.de).

- Four service pages, each aimed at one local search intent, with sitemap and structured data
- Contact form that only confirms when the mail provider accepted the message; works without JavaScript
- Accessible by measurement (contrast ratios, reduced motion, keyboard) and privacy-friendly by default
- Next.js 15, React 19, TypeScript, Tailwind CSS, Resend, Vercel

**[SINI Studio](https://github.com/darkoardeljan/sini-studio-showcase)** — website for a boutique Reformer
Pilates studio in Ljubljana. Live at [sinistudio.si](https://sinistudio.si).

- Plain HTML, CSS and one JavaScript file: no framework, no build step, no dependencies
- No cookies and no third-party requests until the visitor consents; self-hosted, subsetted fonts
- Vector logo taken from the studio's official PDF; security headers and a Content-Security-Policy
- Slovenian-language site
